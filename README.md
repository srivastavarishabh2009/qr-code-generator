# 📱 QR Studio

A modern, fast, and interactive web application for generating customized QR codes built with **React** and **Vite**.

---

## ✨ Features

- ⚡ **Instant Generation:** Create QR codes in real-time as you type or paste content.
- 🎨 **Customization:** Tweak colors, background styling, and formatting options.
- 💾 **Download & Share:** Export high-resolution QR codes for print or digital use.
- 📱 **Responsive Design:** Clean, modern interface designed to work seamlessly across mobile and desktop.

---

## 🛠️ Tech Stack

- **Framework:** [React 19](https://react.dev/)
- **Build Tool:** [Vite](https://vite.dev/)
- **QR Generation:** [qrcode](https://www.npmjs.com/package/qrcode)
- **Styling:** CSS3

---
